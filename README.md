# 牌咖｜拉密計分

一個零依賴、純前端的拉密（Rummikub）計分工具，適合直接部署到 GitHub Pages。

## 功能

- 支援 2–6 位玩家
- 內建 60／90 秒回合計時，一鍵完成並換下一位玩家
- 逾時音效、震動（裝置支援時）與畫面特效，可隨時靜音
- 自動計算每局得分、累積排名與勝局
- 牌局紀錄可個別刪除並重新計算
- 戰況分享／複製
- 使用 `localStorage` 自動保留進度
- 手機優先、無廣告、無需登入

## 計分方式

每局贏家獲得其他玩家剩餘牌分的總和；其他玩家各扣除自己的剩餘牌分。鬼牌以 30 分計。

## 本機預覽

直接開啟 `index.html` 即可，或在專案目錄啟動任一靜態檔案伺服器：

```bash
python -m http.server 8000
```

再開啟 <http://localhost:8000>。

## GitHub Pages

網站只使用相對路徑，可直接從儲存庫根目錄的 `main` 分支發布。
